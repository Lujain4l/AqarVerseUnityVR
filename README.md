# AqarVerse VR

This repository contains the Virtual Reality (VR) component of the AqarVerse platform, developed using **Unity**.  
The VR environment allows users to log in the AqarVerse virtual lobby, where the immersive property experience will take place in later release.

## 🎮 VR Features (Release 1)
- Display a virtual lobby
- Log in to an AqarVerse account inside VR 
- Show clear feedback messages when login fails

## 🛠 Technologies Used
- Unity 2022.3 LTS  
- XR Interaction Toolkit  
- Firebase Authentication (via REST API in Unity)  
- MRTK Virtual Keyboard (NonNativeKeyboard)  
- C# scripts for UI control, authentication flow, and VR interactions  
 

## ▶️ How to Run
1. Open the project using **Unity 2022.3 LTS**  
2. Connect your Meta Quest 3 device for testing  
3. Open the main scene and enter Play Mode  
4. For headset testing, build the project and deploy to the Meta Quest 3


The script handles:
- Email + password login  
- Error handling and UI feedback  
- Maintaining authentication status across scenes
